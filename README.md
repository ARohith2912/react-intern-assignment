# React Developer Intern Assignment

This project is a React-based assignment built as part of the React Developer Intern evaluation.  
It demonstrates core React concepts, component design, state management, and UI handling.

---

## 🛠 Tech Stack

- React (Vite)
- JavaScript (ES6+)
- CSS / Tailwind CSS
- LocalStorage (for persistence)

---

## 📂 Tasks Implemented

### ✅ Task 1: Todo Application
- Add new tasks using a form
- Display tasks in a list
- Delete tasks
- Mark tasks as completed
- Persist tasks using localStorage
- Filter tasks (All / Active / Completed)
- Set task priority
- Responsive and clean UI

---

### ✅ Task 2: Form Handling & Password Toggle
- Fields: Name, Email, ID, Password
- Inline validation for all fields
- Email format validation
- Show / Hide password toggle
- Display submitted data below the form
- Clear form after successful submission

---

### ✅ Task 3: Dynamic Progress Bar
- Multiple numeric input fields (0–100)
- Single main progress bar
- Sub progress bars for each input
- Real-time UI updates
- Color change based on percentage
- Smooth animation
- Prevents invalid values

---

### ✅ Task 4: Advanced Countdown Timer
- Configurable start time (default: 10 seconds)
- Start / Pause / Resume / Reset controls
- Millisecond precision display
- Timer status display (Running / Paused / Completed)
- Prevents multiple timers
- Persistent timer state using localStorage
- Automatically resumes after page refresh

---

### ✅ Task 5: Live Search with Highlighting
- Search input with case-insensitive filtering
- Highlight matching text
- Display count of matching results
- Show “No matches found” when applicable
- Supports multiple highlights

---
